🔴 Blockers — fix before deploy

Critical
.env not in .gitignore
Your .gitignore does not exclude .env. This file holds your DB password, admin token, and Resend API key. If committed, those secrets are in your Git history permanently. Add .env to .gitignore and run git rm --cached .env if it was ever tracked.
Critical
No helmet or rate limiting
The server has no helmet (security headers) and no rate limiting middleware. Without these, the API is exposed to brute-force login attempts, clickjacking, MIME-sniffing, and XSS via missing headers. Install helmet and express-rate-limit.
Critical
Port hardcoded to 5000
app.listen(5000) on line 2515 of server.js ignores the PORT environment variable. Most hosting platforms (Azure, Render, Railway) inject PORT at runtime. Change to app.listen(process.env.PORT || 5000).

🟡 Warnings — should fix

Warning
6 MB hero image ships unoptimized
heading page.JPG is 5.9 MB in the production bundle — larger than the entire JS + CSS combined. Resize to ≤ 400 KB, convert to WebP, and use responsive <img srcset>. This alone will cut first-load time significantly.
Warning
No .env.example file
There's no .env.example documenting which environment variables the project needs. Without it, anyone deploying (including your future self) has to read the source to figure out the config. Create one with all 9 keys and placeholder values.
Warning
API URL scattered across 10 files
The VITE_API_URL || 'http://localhost:5000' fallback is duplicated in 10 separate page files instead of imported from the centralized API client. If the fallback ever needs to change, you'd miss some. Import from src/api/client.ts everywhere.
Warning
trustServerCertificate: true in DB config
Line 314 of server.js trusts any SQL Server certificate. This is fine for local dev but should be false in production when connecting to a properly certified database, or set via an environment variable.
Warning
No NODE_ENV in current .env
Your .env defines 9 variables but not NODE_ENV. Several behaviors differ in production mode (the admin token fallback, Pino log format, CORS). Make sure the deploy platform sets NODE_ENV=production.
Warning
No FRONTEND_URL in .env
CORS origin falls back to http://localhost:5173. In production, FRONTEND_URL must be set to your real domain or the frontend can't reach the API.
